# Simple Quiz

A simple quiz application created to practice programming fundamentals and logical problem-solving. The application presents multiple-choice questions, validates the user's answers, and displays the final score at the end.

## Features

* Multiple-choice questions.
* Automatic answer validation.
* Score tracking.
* Final score display.
* Simple and user-friendly interface.

## Purpose

This project was developed as a learning exercise to improve programming skills, code organization, and user interaction, while serving as a foundation for future enhancements and more advanced projects.
