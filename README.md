# Simple Quiz

A simple quiz application created to practice programming fundamentals and logical problem-solving. The application presents multiple-choice questions, validates the user's answers, and displays the final score at the end.

##Features
- four quiz categories:
  - Mathematics
  -History
  - Geography
  - Biology
- Automatic score calculation.
- Simple terminal interface.

## Purpose

This project was developed as a learning exercise to improve programming skills, code organization, and user interaction, while serving as a foundation for future enhancements and more advanced projects.

##Requirements
-Python 3.x
- Visual Studio Code (recommended)

## How to Use

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open the `quiz.py` file.
4. Click the **Run** button (▶) in the top-right corner or run the file using the VS Code terminal.
5. Follow the on-screen instructions and answer the quiz questions.
